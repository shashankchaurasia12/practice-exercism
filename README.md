# C# & .NET Practice

A personal learning repository focused on building strong C# and .NET development skills through hands-on practice, Exercism exercises, and progressively more complex projects.

## Repository Structure

### csharp/

C# exercises and solutions from Exercism.

The goal is to strengthen:

- C# fundamentals
- Object-oriented programming
- Collections and LINQ
- Exception handling
- Generics
- Interfaces and abstractions
- Algorithms and problem solving
- Testing

### projects/

Personal C# and .NET projects created to apply concepts in practical scenarios.

As the projects become more complex, they may incorporate:

- .NET
- ASP.NET Core
- Web APIs
- Entity Framework Core
- CQRS
- Domain-Driven Design
- Clean Architecture
- Automated testing
- Git and CI/CD

### 
otes/

Learning notes and technical references organized by topic.

- 
otes/csharp/ — C# concepts
- 
otes/dotnet/ — .NET concepts
- 
otes/git/ — Git and GitHub
- 
otes/architecture/ — Software architecture and design

## Learning Approach

The repository follows a practical progression:

1. Build strong C# fundamentals through small exercises.
2. Practice problem solving with Exercism.
3. Apply concepts through personal projects.
4. Gradually introduce professional .NET development practices.
5. Explore architecture, testing, and design patterns as project complexity increases.
6. Maintain clean Git history and documentation throughout the process.
